# AI Support Agent Backend

A learning project built using FastAPI and Google Gemini AI. Users can submit queries, and the system generates AI-powered responses using Gemini AI.

## Technologies Used
- Python
- FastAPI
- Google Gemini AI
- Uvicorn

## Features
- AI-powered query handling
- FastAPI REST API
- Gemini AI integration

## Purpose
This project was created during a learning workshop to explore FastAPI, API development, and AI integration concepts.
